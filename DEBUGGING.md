# Debug Logging

Set `DEBUG=true` in this repo's `.env`, then run:

```sh
docker compose -f compose.yaml -f compose.local.yaml up -d --build
docker compose -f compose.yaml -f compose.local.yaml logs -f backend indexer
```

The same flag configures the API, indexer, and master frontend.
Set `DEBUG=false` (the default) and repeat `up -d` to disable it.
An env change requires container recreation; `restart` alone does not apply it.
Accepted true values: `true`, `1`, `yes`, `on` (case-insensitive).

Events cover API timing/status, index inputs, missing or malformed snippet
metadata, per-species indexing, best-clip selection, API serialization, and audio
streaming. Request logs exclude headers, query strings, and bodies.
Existing operational logs and real warnings/errors remain visible.

If a player is absent, trace `snippets.missing_index` -> `snippets.loaded` ->
`snippet.indexed` -> `species.serialize` -> browser `species.render`.
Clips must be generated by the compute stack first. Both manual indexing and the
watching indexer now consume the snippet metadata.

Use `from app.debug import debug` and small `debug("event.name", count=value)` calls.
